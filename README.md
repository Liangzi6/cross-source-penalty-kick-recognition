This repository accompanies the manuscript Cross-source penalty-kick direction recognition under domain shift: a reproducible pose-visual study. It contains the code and de-identified derived features needed to reproduce all experiments in the paper.

This archive contains de‑identified derived features. Raw images are not included; all paper experiments can be reproduced using only these feature files.

Structure
src/ — preprocessing, training, evaluation, statistics and plotting code

configs/ — frozen protocol, class order, seed and environment settings

data_derived/ — de-identified features, folds, predictions and evidence workbook

DATA_DICTIONARY.md — column descriptions for each data file

requirements.txt — pinned software versions

File Manifest.json — file checksums
